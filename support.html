VIBEPAD support

For Vercel connections, start with the connection guide. Choose the account or team where you want to publish, approve access to new projects, and return to your original build tab.

For a website that is still publishing, choose Check publishing. For a custom domain, copy the DNS records shown for your project and choose Check connection after saving them with your DNS provider.

A saved coin launch can be checked from the home page. Keep its original transaction and website references while confirmation is pending.

Contact jacknoel.e@gmail.com with the public project link and a description of the issue. Do not send API keys, wallet private keys, or recovery phrases.
