01Getting started

Describe what you want to make on the home page, then choose Build your idea. You can start building without connecting a wallet or supplying an API key.

Build your first idea ↗

02Build and edit

A useful prompt describes what the website does, who it is for, and the style you want. Include the sections, buttons, or interactions that matter to you.

Build a portfolio for a product designer. Use a dark background, large type, three project cards, and a contact section. Keep it simple and make it work on mobile.

When the first version appears, use the builder's message box to request changes. Be specific: “Make the header smaller” or “Add a filter to the project list.” Use Preview to try the website, the desktop and mobile controls to check its layout, and Code to inspect its HTML.

The current builder creates a single HTML page, suited to landing pages, portfolios, and interactive demos. Its interactions run locally; connections to live services are not supported.

Keep the builder tab open while you work. Unpublished drafts are held in the current session. Choose Download code to save an HTML copy before refreshing or leaving the builder.

03Name and logo

Choose Launch in the builder to open the branding and publishing steps. Set your project name and coin ticker, describe the logo you want, then choose Generate logo. Select the version you want to use.

Coin names support up to 32 bytes, so some characters take more space than others. Tickers use 1–13 uppercase letters or numbers. The name, logo, and website are included in the coin's public details.

04Publish your website

  1. Choose Connect your Vercel account and sign in.
  2. Select the account or team where you want your website to live. Approve access to new projects.
  3. Return to the builder tab and choose Publish website.
  4. Wait for Website published, then open the public link to check your site.

Your website gets a .vercel.app address in the Vercel account you connected. You can publish a website without signing a coin launch. Review launch also publishes the website if it is not ready yet.

If you change the website, name, or logo after publishing, publish the latest version before reviewing your coin. Publishing a changed version creates a new project and Vercel address. Check the new public link before launching.

Vercel connection guide ↗

05Custom domains

Your Vercel address is ready to use. A custom domain is optional, and you can connect one after the website is published.

  1. Open Custom domain. Use the Spaceship link to search for and purchase a domain, or use a domain you already own.
  2. Enter the domain name, such as youridea.com, and choose Connect.
  3. Add the exact DNS records shown in VIBEPAD to your domain provider's DNS settings.
  4. Choose Check connection. DNS changes can take time to appear; check again until the status says Connected.

Connect and verify the domain before reviewing your coin if you want it used as the token's website. While DNS is pending, the Vercel address stays available. Spaceship handles its own domain pricing and checkout.

06Launch on Pump.fun

Choose Connect wallet to select your Solana wallet through Privy. Connecting your wallet does not create a coin or approve a transaction.

  1. Finish the name, ticker, logo, and website, then choose Review launch.
  2. Check the token's website, launch wallet, coin address, and estimated SOL cost.
  3. Choose Sign & launch coin and review the approval in your wallet.
  4. Wait for confirmation. Use the resulting link to open your coin on Pump.fun.

The launch creates your coin on Solana mainnet and attaches your published website to its Website field. The current launch flow has no initial token purchase. Your wallet pays the account and network costs shown in the review.

08Your projects

Choose My projects on the home page to find projects saved during publishing. Opening a project takes you to its website or project page.

Project access is tied to this browser. Keep your public website links and downloaded HTML copies if you want to use them from another device. An unpublished builder session is separate from the published project list.

09Troubleshooting

A build did not finish.

Keep the builder open and choose Try again. If a daily limit message appears, return when the limit resets.

The website is still publishing.

Choose Check publishing. If Vercel access needs updating, reconnect the account that published the website and approve publishing access.

A custom domain is waiting for DNS.

Compare the records in your provider's settings with the exact values shown in VIBEPAD, then choose Check connection after the changes have had time to appear.

A coin launch is pending.

Choose Check status in the launch window, or open the saved launch from the home page. Check the original launch before starting another one; an interrupted response can still leave a transaction waiting for confirmation.
